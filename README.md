# SCT_CS_1
Caesar Cipher – Encryption & Decryption

📌 Overview

This project is a simple Caesar Cipher implementation in Python. It allows users to encrypt and decrypt messages using a user-defined shift value.

The project demonstrates the basic concept of classical cryptography and substitution-based encryption.

✨ Features

* 🔐 Encrypt messages using Caesar Cipher
* 🔓 Decrypt encrypted messages
* 🔢 Supports custom shift values
* 🔤 Supports uppercase and lowercase letters
* 📝 Preserves spaces, numbers, and special characters
* 💻 Simple command-line interface

🛠️ Technologies Used

* Python
* Visual Studio Code

⚙️ How It Works

The Caesar Cipher shifts each alphabetic character by a specified number of positions.

For example, with a shift value of 3:

Original:  Hello World
Encrypted: Khoor Zruog

During decryption, the characters are shifted backward by the same number.

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python3 caesar_cipher.py

5. Enter your message.
6. Enter the shift value.
7. Select Encrypt or Decrypt.
